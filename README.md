A one-line roast of the AI agent its own maker built, entered in the [Roast Your Own Agent](https://make.fun/competitions/u-nayyy-roast-your-own-agent-4c3d413c) competition on [make.fun](https://make.fun).

## Entry

> My agent is so good at roasting itself that it just filed a bug report against its own personality and marked it wontfix.

## How it works

`main.py` (Python standard library only) writes the roast to `/output/entry.txt` and sets its permissions to `0644` so the grader can read it.
